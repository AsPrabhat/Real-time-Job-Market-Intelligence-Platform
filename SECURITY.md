# Security

## Reporting Security Issues

If you discover a security vulnerability, please email: **prabhatworkspace@gmail.com**

Please do NOT open a public issue for security concerns.

## Security Best Practices

**For Email Alerts:**
- Use Gmail App Password (not your regular password)
- Generate at: https://myaccount.google.com/apppasswords
- Never commit `.env` file with credentials

**For Docker:**
- Don't expose ports to public networks in production
- Keep Docker Desktop updated
- Review resource limits

**Note:** This is a learning project for portfolio/academic purposes. For production use, implement proper authentication and security measures.
